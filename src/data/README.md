# Timezone city names

`timezone-cities.json` contains English and Japanese exemplar city names from
[Unicode CLDR](https://github.com/unicode-org/cldr-json), `cldr-dates-full/main/{en,ja}/timeZoneNames.json`.
The Unicode license is included in `UNICODE-LICENSE.txt`.
These names and `@vvo/tzdb` validate geographic evidence for timezones.
